Cabinet status key

Header lights show the last reported status. Hover or focus for its label. Studio reports a session, not a process check.

Idle

Online, with no active table reported.

Busy

Studio reports an active table. Play stays blocked.

Offline

The last check could not reach the cabinet.

Unknown

No usable current status is available.

Stale

The saved status is more than 125 seconds old with no table reported. A reported active table keeps the busy light. Play stays blocked until a fresh idle check.

Background collection

Status is checked every 60 seconds. Bulk reads wait while the cabinet is busy. Offline checks back off up to 15 minutes. No image downloads or table launches are started.

Library sync

Header Sync updates the table list, caches new, changed or unavailable images, and preloads table details and score history sequentially while idle. Cache progress appears in this menu. Fresh table data is skipped. Refresh updates scores, play counts and status without starting a cache job.

Full re-sync refreshes every table image from the cabinet. Existing images stay available until replacements succeed. This may take several minutes and pauses while the cabinet is busy or offline.
